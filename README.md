# Robot and Data

## 프로젝트 소개

현 레포지토리는 시뮬레이션으로 로봇 인공지능을 학습하는 간단한 시스템을 제공합니다. 우리는 이 시스템을 통해 다양한 사람들이 인공지능을 로봇에 적용되는 방식을 깨닫는데 도움이 될 것이라고 생각합니다. 

## 배경 설명

로봇에 인공지능을 접목하는 것에는 많은 것이 필요합니다. 그 중에서도 가장 직접적으로 요구되는 것은 현실 세계에서 로봇이 의도한대로 명령을 수행하는 것입니다. 

현실에서 로봇을 움직이고, 이를 기반으로 인공지능을 학습하는 것은 많은 제약이 따릅니다. 보통은 시간과 자금의 문제에 부딪히게 됩니다. 이러한 문제를 완화하기 위해 시뮬레이션 학습은 적극적으로 활용되고 있습니다. 

로봇과 인공지능에 대한 지식을 익히는 데에 있어, 반드시 로봇이 실제로 구비될 필요는 없습니다. 이러한 점들을 기반으로 하여, 현 프로젝트는 오로지 가상 환경, 즉 시뮬레이터만을 사용하여 시스템을 구성하게 되었습니다. 

분명히 할 점은, 이 시스템을 통해 학습된 인공지능이 현실의 로봇에 적용될 수 없는 것은 아니라는 점입니다. 


## 시스템 설명

![architecture](docs/Architecture%20Ver.2.png)

시스템은 크게 시뮬레이터와 파이프라인으로 구성됩니다. 시뮬레이터를 통해 가상 환경에서 인공지능에 의해 제어받는 로봇을 움직이고 데이터를 생성하면, 그 데이터를 적합한 절차를 통해 저장하고 사용합니다. 

시뮬레이터에서 생산된 데이터로 인공지능을 학습하고, 학습된 인공지능으로 시뮬레이터에서 새롭게 데이터를 생성하는 것으로 완전히 반복된 작업을 구상할 수 있습니다. 그리고 이는 곧 자동화를 적용할 수 있다는 의미이기도 합니다. 

이를 기반으로 우리는 단순히 인공지능을 학습하는 것을 넘어, 자동화 시스템의 구현까지 진행하였습니다.
